🌸 Career Quest
Career Quest is a Krishna-inspired Android career productivity tracker designed to help students organize daily goals, track learning progress, maintain consistency, and monitor their career growth.

✨ Features
- 📅 Today — Track daily progress and completion.
- 💻 LeetCode Counter — Track completed coding problems.
- 🧠 Aptitude Counter — Track aptitude practice.
- ✅ To-Do Tracking — Manage daily tasks.
- 💼 LinkedIn Progress — Track weekly activity.
- 🐙 GitHub Progress — Track weekly contributions.
- 📝 Notes — Create, edit, search, categorize, pin, and favorite notes.
- 📊 Progress Analytics — View weekly and monthly progress.
- 🔥 Streak Tracking — Maintain consistency.
- ⭐ XP & Levels — Earn XP through completed activities.
- 🏆 Achievements — Unlock career and consistency achievements.
- 🎵 Background Music — Optional peaceful Krishna-inspired instrumental music.
- ⚙️ Settings — Customize targets, XP configuration, appearance, animations, and preferences.
- 📆 Daily History — Previous progress is preserved by date.
  
🎨 Design
The app uses a Vrindavan-inspired visual theme featuring:
- Krishna and Radha artwork
- Peacock-inspired colors
- Lotus elements
- Antique-gold accents
- Glass-style cards
- Golden sparkles and decorative elements
- Peaceful garden/palace atmosphere
The design is intended to provide a calm and motivating environment while keeping the app focused on career productivity.
🛠️ Technology
- Kotlin
- Jetpack Compose
- Android
- Google AI Studio Build Mode
  
📱 Navigation
The application contains four main sections:
Today → Progress → Notes → Settings
🎯 XP System
Activity	XP
LeetCode problem	+5 XP
Aptitude question	+1 XP
LinkedIn weekly target	+5 XP
GitHub weekly target	+10 XP


XP cannot fall below zero.
🚀 Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize.
4. Connect an Android device or start an emulator.
5. Build and run the application.

📦 APK
A release APK can be provided through the project's GitHub Releases section.
Example:
CareerQuest-v1.0.0.apk

🔒 Data
Career Quest is designed to maintain the user's actual progress rather than relying on demonstration data. A fresh installation starts without pre-filled sample activities or notes.
